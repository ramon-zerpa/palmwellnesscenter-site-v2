# Palm Wellness Center — Design System (MASTER)

Source of truth for tokens, typography, and component rules.
Generated by **UI/UX Pro Max** (pattern: *Trust & Authority + Conversion*; style: *Accessible & Ethical*), adapted to the **logo-derived brand palette** (logo is immutable).

---

## 1. Brand foundation

- **Logo:** immutable. Green "PALM" + blue "WELLNESS CENTER" + palm/spine mark.
- **Palette:** logo-derived blue and green, supported by a pale cyan-blue information surface and
  neutrals. No purple or unrelated gradient system.
- **Tone:** trustworthy, clinical, warm, bilingual, accessible. Not corporate-cold, not playful.

## 3. Typography

- **Headings:** `Figtree` (600/700)
- **Body:** `Noto Sans` (400/500)
- Fallbacks: `system-ui, sans-serif`

| Token | Size / LH | Use |
|---|---|---|
| `--fs-h1` | 32–44px / 1.15 | Page H1 (fluid) |
| `--fs-h2` | 26–34px / 1.2 | Section headings |
| `--fs-h3` | 20–24px / 1.3 | Card/subsection |
| `--fs-body` | 16–18px / 1.65 | Paragraphs |
| `--fs-small` | 14px / 1.5 | Captions, disclaimers |
| `--fs-eyebrow` | 12–13px / 1.4, +tracking | Section eyebrows |

Body never below 16px. Measure 60–75ch. `text-wrap: balance` on headings, `pretty` on intros.

## 4. Spacing / layout

- Base unit **4px**; scale 4, 8, 12, 16, 24, 32, 48, 64, 96.
- Container max-width 1200px + `clamp()` gutters.
- Section vertical rhythm: 48px mobile → 96px desktop.
- Grid: 12-col desktop, single col mobile.

## 5. Shape & elevation

- Radius: `--r-sm 6px`, `--r-md 10px`, `--r-lg 16px`, `--r-pill 999px`.
- Shadows: subtle only (`0 1px 2px rgba(22,78,147,.06)`, `0 8px 24px rgba(22,78,147,.08)`). No dark glows.

## 6. Motion

- Duration 150–300ms, `ease-out` in, faster out. No bounce/elastic.
- Respect `prefers-reduced-motion` (static final state). Carousels: keyboard prev/next + pause; stop on focus/hover/reduced-motion.

## 7. Components (rules)

- **Header:** utility bar on desktop (address · hours · licenses) and address only on mobile;
  main nav + persistent **Book** CTA. Sticky on scroll.
- **Nav:** Primary Care first; grouped dropdowns; language switcher is a compact EN/ES pill next
  to Book on desktop and at the bottom of the expanded mobile menu. Active language is deep blue;
  the alternate language is `--brand-blue-pale`; no heavy border.
- **Buttons:** primary (blue, white text), secondary (outline blue), tertiary (text link). Min 44×44px. Visible focus. No layout-shift on press.
- **Cards:** one level only; no nested cards. Icon + title + copy + link.
- **Badges/Chips:** color + text (never color alone). "Coming Soon" uses `--brand-green-bright`/dark text.
- **Forms:** visible labels, inline validation, linked error summary on multi-error submit.
- **Pricing/membership:** side-by-side comparison table, transparent, CTA per column.
- **Accordion (FAQ):** native semantics, `aria-expanded`, keyboard operable.
- **Hero:** content left/image right. Image lives in a shadow frame; use full-image slide-in from
  the right, subtle resting drift, heartbeat badge and vital-line detail. Set `object-position`
  per photo after testing both desktop and mobile; never let `object-fit: cover` crop a face.
- **Footer:** full NAP, hours, licenses, columns for Primary Care and Physical Rehabilitation;
  legal links centered in the bottom bar; True Webmaster credit right; social and Brand Hub are
  text-only `--brand-blue-pale` pills.

## 8. Accessibility (non-negotiable)

Contrast ≥4.5:1 text / ≥3:1 UI. Visible focus everywhere. Semantic heading order (one H1). Alt text strategy. Skip link. 44px targets. No color-only meaning. Test 375/768/1024/1440 + reduced-motion + 200% zoom.

## 9. Anti-patterns to avoid

AI purple/pink gradients · emojis as icons · gray text on colored backgrounds · pure black · nested cards · icon tile above every heading · bounce easing · dark glows · opaque/opaque-slop hero stock · auto-rotating carousels without controls.
